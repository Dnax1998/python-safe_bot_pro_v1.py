# 🏙️ Crypto Avenue — On-Chain Web3 Billboard City

Decentralizowana siatka reklamowa inspirowana koncepcją Million Dollar Homepage i Claim Avenue, oparta na smart kontraktach i płatnościach Web3.

## 🚀 Funkcje
- **100 Unikalnych Działek Reklamowych** w modelu siatki 10x10.
- **W pełni decentralizowana aplikacja (dApp):** Rejestracja powierzchni reklamowych odbywa się on-chain.
- **Obsługa Portfeli Web3:** Integracja z MetaMask / Coinbase Wallet poprzez Ethers.js.
- **Responsywny UI:** Zbudowany w oparciu o HTML5, Tailwind CSS i Font Awesome.

## 🛠️ Jak uruchomić lokalnie lub na GitHub Pages?
1. Sklonuj repozytorium lub pobierz pliki.
2. Otwórz `index.html` w dowolnej przeglądarce.
3. Połącz portfel MetaMask i testuj interfejs.

## 📜 Wdrożenie Smart Kontraktu
1. Skopiuj kod z pliku `CryptoAvenue.sol` do [Remix IDE](https://remix.ethereum.org/).
2. Wybierz sieć (np. Base Sepolia / Polygon / Arbitrum).
3. Kliknij **Deploy**.
4. Wklej wygenerowany adres kontraktu do zmiennej `CONTRACT_ADDRESS` w pliku `index.html`.
